# Google Cybersecurity Certificate — GRC Audit Project

A GRC (Governance, Risk, and Compliance) assessment for **Botium Toys**, a fictional company used in the Google Cybersecurity Certification course. This project evaluates security controls and compliance posture against three major frameworks: PCI DSS, GDPR, and SOC 2.

## About This Repository

This repo contains two versions of the same assessment:

- **`my-security-audit.pdf`** — my original completed checklist and recommendations, submitted as part of the Google Cybersecurity Certificate coursework.
- **`Botium_Toys_Security_Controls_Compliance_Assessment.md`** — a cleaner, reformatted version of the same document, created with the assistance of Claude AI. The AI reorganized the checklist into readable tables and improved formatting; the underlying control evaluations, compliance findings, and recommendations are my own original work from the certificate coursework.

I'm including both versions intentionally — to be transparent about how I use AI tools, and to demonstrate that I can use them responsibly to improve presentation without letting them replace my own analysis.

## What This Project Covers

- Controls Assessment — evaluating 14 security controls, such as least privilege, encryption, backups, disaster recovery, physical security, etc, against what the fictional company Botium Toys currently has in place
- Compliance Assessment — checking Botium Toys' practices against:
  - Payment Card Industry Data Security Standard (PCI DSS)
  - General Data Protection Regulation (GDPR)
  - System and Organization Controls (SOC Type 1 & 2)
- Recommendations — prioritized guidance on which controls and compliance gaps to address first, based on risk
